# arch-v2 架构重设计（GDD v5 增补）

> 来源方案：Cursor Page「draft-arena 最优架构重设计与迁移方案」（2026-10-22）。本文件是 arch-v2 分支的设计冻结（M0），
> 与 docs/GDD.md 并存：GDD 描述玩法现状，本文件描述目标架构与迁移顺序。引擎沿用 Godot 4.4.1，渲染器保持 gl_compatibility。

## 1. 设计支柱（每条带可测指标）

| 支柱 | 目标 | 指标 |
|---|---|---|
| 共鸣雪球 | 3 分钟内 Build 成形并可命名 | 试玩 ≥50% 局主动追某一标签共鸣；sim 各标签 Build 胜率差 ≤15pp |
| 一键操作感 | 自动攻击外只有一个主动键（冲刺/闪身，带无敌帧） | 每分钟冲刺 ≥4 次；「被包围致死」占比下降 |
| 每一击都有回应 | 闪白 + hit-stop 分级 + 方向性伤害数字 + 击退曲线 + 分层音效 | 5 人盲测打击感评分 ≥4/5 |
| 10 秒上手、8–12 分钟一局 | 前 30 秒出现第一次爽点 | 首次击杀 ≤10s；首次升级 ≤30s |
| 可分享 | 结算 Build 卡片 + 种子码，同种子可复现 | 固定种子下 sim 结果逐局一致 |

## 2. 标签表（M2 实装共鸣，M1 先落数据）

| 标签 | 含义 | 现有归属 |
|---|---|---|
| bullet | 投射物 | 龙狙、狙击、散弹；二连发、弹射透镜 |
| boomerang | 回旋 | 回旋镖 |
| arc | 电弧/链式 | 电弧 |
| melee | 近身环绕 | 环刃 |
| crit | 暴击 | 致命一击、巨人杀手 |
| survival | 生存 | 铁砧、再生、板甲、荆棘、吸血獠牙 |
| fury | 低血/风险收益 | 狂暴、复仇、背水、玻璃大炮 |
| tempo | 速度/节奏 | 弹药带、跑鞋、疾风 |
| greed | 经济 | 磁石、黄金子弹 |
| control | 控制 | 冰霜符文 |
| blast | 爆炸 | 爆裂弹 |

共鸣阈值 2/4/6；进化配方 = 武器 Lv3 + 指定标签计数（M2 定稿）。

## 3. 反馈预算（M4 实装）

hit-stop：普通 0 ms、暴击 30 ms、精英击杀 60 ms、首领阶段 120 ms；同屏伤害数字上限 60（同帧同目标合并）。

## 4. 分层与目录

- `scripts/core/`：规则层（Resource 类、修饰符、EventBus），不得引用场景节点之外的表现逻辑，可 headless 单测。
- `content/`：纯数据 .tres。新增武器升级卡/被动 = 新建一个 CardDef .tres 并登记到 content/card_library.tres，不写代码。
- 表现层（fx/audio/ui）逐步改为订阅 EventBus。
- 约束：单文件新增代码 ≤400 行；新内容必须是数据。

## 5. 里程碑

M0 设计冻结 → M1 数据底座 → M2 规则引擎与共鸣 → M3 战斗世界重构（空间哈希 + MultiMesh + 冲刺）→ M4 表现层 → M5 循环加深 → M6 可分享与内容扩产。每个里程碑必须可玩、本地 headless 全测通过、CI 全绿。
